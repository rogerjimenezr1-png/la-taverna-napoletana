# La Taverna Napoletana

Proyecto web para el restaurante **La Taverna Napoletana** (Mataró, Barcelona).

## Estructura del proyecto

```
la-taverna-napoletana/
├── index.html         → Página principal
├── css/
│   └── styles.css     → Todos los estilos de la web
├── js/
│   └── main.js        → JavaScript (navegación, animaciones, menú)
├── img/
│   ├── img_01.jpg     → Imagen 1 (logo / hero)
│   ├── img_02.jpg     → Imagen 2
│   └── ...            → Resto de imágenes
└── README.md          → Este archivo
```

## Cómo editar

- **Textos y estructura**: edita `index.html`
- **Colores, fuentes y estilos**: edita `css/styles.css`
- **Comportamiento (menú, scroll, animaciones)**: edita `js/main.js`
- **Imágenes**: reemplaza los archivos en la carpeta `img/`

## Variables CSS principales (en styles.css)

```css
--cream: #F5EFE6
--red: #9B2C2C
--olive: #4A5E28
--black: #0D0D0D
```
